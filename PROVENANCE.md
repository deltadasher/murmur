# Source provenance

This project was created and substantially developed with Codex coding agents.
Human input supplied the product brief, platform requirements, design feedback
and requests for changes. The majority of the implementation artifacts in this
source tree were authored or revised by agents, including the C++ application,
DSP and daemon, tests, documentation, packaging files and CI configuration.

This is an approximate description of authorship, not a line-by-line audit.
Validation evidence is recorded separately in [VALIDATION.md](VALIDATION.md).
An automated test or visual inspection does not establish that a human maintainer
has audited all source or accepted responsibility for a public release.

The developer Flatpak manifest is AI-authored and is intended for local builds.
It is not suitable as a Flathub submission manifest under Flathub's current
[generative AI policy](https://docs.flathub.org/docs/for-app-authors/requirements#generative-ai-policy).
That policy requires disclosure of included generated material, forbids generated
or assisted submission manifests, and reserves submission and review interaction
for human submitters. A public Flathub release needs independent human packaging
and review, as well as the technical validation described in [PACKAGING.md](PACKAGING.md).
