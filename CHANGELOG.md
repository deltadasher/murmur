# Changelog

## 0.3.0 — 2026-10-01

- Introduce the native voice console: Tone, Character, Cleanup and Space, with
  persistent routing/session controls and a compact preset selector.
- Add low cut, threshold gate, compression, drive, echo amount and echo time,
  plus the Comms preset. Older presets load new effects as Off.
- Add keyboard module navigation, per-slider reset, precise values and clearer
  recovery layouts for small windows.
- Add developer Flatpak packaging, separate sandbox IPC, background permission
  handling and kernel locking across worker PID namespaces.
- Add native/Flatpak CI, release documentation and expanded DSP, portal, UI
  and synthetic audio integration coverage.

## 0.2.2

- Refine the tone/texture workbench, compact controls and system-mute recovery.

## 0.2.1

- Add independent background audio, reconnect/restart handling, user installation
  and synthetic audio lifecycle verification.
